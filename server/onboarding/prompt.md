## Workspace plan

Return each option using the provided schema:

### Name and icon

A short workspace name in sentence case and one relevant built-in Moi icon ID. Moi supplies the icon background.

### Theme

Only font and color, using preset IDs from the schema. Each of the three options must have a different font and color.

### Description

One or two short sentences, at most 280 characters: what the workspace does and why it would help this person. Mention context broadly and naturally; omit exact dates, meeting titles, people's names, quotes, and research details.

### Views and widgets

Include exactly three full-page views and optionally up to four focused Overview widgets. For each, provide:

- A sentence-case name.
- For each view, a relevant built-in Moi icon ID to use when building it. Within each option, the workspace icon and all view icons must be different from one another.
- A short description of its purpose and content.
- Concrete features covering actions, behavior, data sources, and saved state. For widgets, include the main action or link to a view where useful.

Keep each plan small and ready for another agent to build. Put useful source references and access limitations in the features, without private transcripts or secrets. Do not promise integrations you haven't verified or return a separate free-text brief.
